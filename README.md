# Training

https://justiiiiiin.github.io/Training/

Fitness Coach: Training, Essen und Fortschritt. Eine einzelne Webseite (`index.html`), die sich auf dem iPhone wie eine App installieren lässt.

- `index.html`: die ganze App
- `sw.js`: Offline-Betrieb (mit Netz kommt immer die neueste Version)
- `manifest.webmanifest`: Name, Farben und Symbole für den Home-Bildschirm

## Entwicklung

- `CLAUDE.md`: Aufbau, Befehle und Hinweise für Claude Code
- `tests/`: automatische Tests (Playwright), Start mit `bash tests/run_all.sh`
- `tools/`: Versionsstempel und Rezept-Werkzeuge
